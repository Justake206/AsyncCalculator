# Async Calculator on Qt (Асинхронный калькулятор на Qt)

Лабораторная работа №1 по курсу «Кроссплатформенное программирование».
**Вариант:** Продвинутый уровень, №5 — *Асинхронный калькулятор с QFuture/QThread*.

## Описание

Консольное приложение-калькулятор, демонстрирующее механизм сигналов и слотов Qt
в многопоточном режиме. Каждая арифметическая операция выполняется в **отдельном
потоке** (`QThread`), результат возвращается в главный поток через сигнал
`resultReady(double)`.

Основная цель работы — изучить метаобъектную систему Qt (МОС), наследование от
`QObject`, объявление собственных сигналов и слотов, установку соединений через
`QObject::connect()` и применение этих механизмов в асинхронном контексте.

## Возможности

- Асинхронные арифметические операции: `add`, `sub`, `mul`, `div`
- Обработка ошибок через сигнал `errorOccurred(QString)`:
  - деление на ноль
  - неверный формат команды
  - нечисловые операнды
  - попытка запустить вторую операцию во время выполнения первой
- Сигнал `operationStarted(QString)` для уведомления о старте операции
- Команды управления: `reset`, `help`, `quit`
- Корректный вывод русского текста в консоли Windows (UTF-8)

## Архитектура

Проект состоит из двух классов-наследников `QObject` и точки входа:

- **`Worker`** — выполняет одно вычисление в отдельном потоке и излучает
  сигнал `finished(double)`.
- **`Calculator`** — управляет потоками:
  - создаёт `QThread` для каждой операции
  - перемещает `Worker` в поток через `moveToThread()`
  - связывает сигнал `Worker::finished` с обработкой результата
  - излучает сигналы `resultReady`, `errorOccurred`, `operationStarted`

## Требования

- **Qt 6.8.3** (или выше), собранный под **MSVC 2022 64-bit**
- **Visual Studio 2022** с расширением **Qt Visual Studio Tools** версии 3.5+
- ОС: **Windows 10/11** (проверено на Windows 10 Pro x64)
- Стандарт C++17

## Сборка

### Через Visual Studio (основной способ)

1. Откройте `AsyncCalculator.sln` в Visual Studio 2022.
2. Убедитесь, что выбраны конфигурация **Debug** и платформа **x64**.
3. Проверьте, что в **Расширения → Qt VS Tools → Qt Versions** зарегистрирован
   путь к `qmake.exe` (например, `C:\Qt\6.8.3\msvc2022_64\bin\qmake.exe`).
4. **Сборка → Пересобрать решение** (`Ctrl+Shift+B`).
5. Запуск: `Ctrl+F5` (без отладки).

### Через qmake (опционально)

В командной строке, где доступны `qmake` и `nmake`:

qmake AsyncCalculator.pro
nmake
release\AsyncCalculator.exe

Особенности реализации
Асинхронность
Каждая операция выполняется в новом QThread. Это видно по отладочному выводу:
Worker thread id отличается от ID главного потока. Такой подход демонстрирует
корректную работу сигналов и слотов между потоками — Qt автоматически
использует Qt::QueuedConnection при передаче сигнала из рабочего потока в главный.

Обработка ошибок
Все ошибки проходят через сигнал errorOccurred. Деление на ноль проверяется
до запуска потока (через qFuzzyIsNull()), чтобы не создавать поток зря.
